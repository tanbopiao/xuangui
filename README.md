# axiom-mcp — 矛已登顶热榜，盾来了

> 矛：让 AI 一条命令拆开一切的逆向工具，9 天登顶热榜。
> 盾：axiom-mcp，一段配置给任何智能体装上可信验证——假设矛到处都是，照样防得住。
> 矛与盾同一片战场，同一批 AI 智能体用户。

## 一句话

把 AxiomGate 的可信验证三件套——**HMAC 严格验签、外部锚点比对、红队探针自测**——变成标准 MCP 接口。作品自带锁；axiom-mcp 把锁变成所有智能体都能插的通用插座。

## 矛与盾

逆向工具攻「看懂」这一层：闭源二进制、加壳混淆，AI 一条命令拆开。axiom-mcp 守「可信」这一层：安全不靠藏、全靠验——代码随便看，混淆随便破，钥匙不在代码里，验签对规范化字节重算，改一个字节、套一层编码、拆包重包，探针当场识破。

盾每天对着矛的招法排练：探针组防的编码混淆（Base64 套娃、十六进制伪装、嵌套回执），与逆向攻防中「加壳免杀」是同族技巧。矛越锋利，盾的排练越真实。

## 30 秒接入

在智能体的 MCP 配置里加一段（零第三方依赖，只要 Python 3.10+）：

```json
{
  "mcpServers": {
    "axiom-mcp": {
      "command": "python3",
      "args": ["/path/to/axiom-mcp/server.py"],
      "env": { "AXIOM_KEY": "<你的64位hex密钥>" }
    }
  }
}
```

然后智能体即可调用四个工具：

| 工具 | 作用 |
| --- | --- |
| `trust_verify_receipt` | 验证回执：规范化重算 HMAC + 时间新鲜度 + 外部锚点 |
| `trust_run_probes` | 红队探针组：篡改 / Base64 混淆 / 双重编码 / 嵌套回执 / 锚点调包 / 过期时间戳 |
| `trust_health_report` | 体检报告 + 证据边界声明 |
| `trust_make_receipt` | 签发回执（演示 / 测试） |

## 三大能力

1. **验签**：对规范化字节重算 HMAC-SHA256，常数时间比较；键顺序、Unicode 一视同仁。
2. **探针**：服务可以对自己打红队——已知攻击形状全部拒绝，才算健康。
3. **证据边界**：每个判定都标注「直接观察 / 推断」，不伪造确定性，不篡改历史。

## 与 AxiomGate 的关系

AxiomGate（元极恒一闸机）是内嵌在作品里的锁；axiom-mcp 把这把锁抽成标准接口。两者共享同一条进化纪律：**只增不覆盖，版本可生长**。

## 对标

| | REA（逆向一切） | axiom-mcp |
| --- | --- | --- |
| 形态 | CLI + MCP 服务器 | MCP 服务器（零依赖） |
| 能力 | 统一逆向工具 | 统一可信验证 |
| 接入 | 一条命令 | 一段 JSON 配置 |
| 争议面 | 逆向授权风险 | 仅验证自身数据，无逆向 |

## 证据边界声明

本作品所有安全判定基于当次输入的规范化重算与直接观察；推荐的置信度表述属于推断，不构成绝对证明。服务不联网、不外发数据、不存储历史状态。
