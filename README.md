# 玄圭（Xuangui）— 矛已登顶热榜，天赐之圭来了

> 禹治水功成，天赐玄圭，告成功于天。
> 玄圭，是华夏文明里**第一件「验证通过」的凭证**：大功告成，上天验讫，授圭为信。
> 三千年后，我们把它重铸成给 AI 智能体的验证之圭。

## 一句话

把 AxiomGate（元极恒一闸机）的可信验证三件套——**HMAC 严格验签、外部锚点比对、红队探针自测**——变成标准 MCP 接口。作品自带锁；玄圭把锁变成所有智能体都能插的通用插座。

## 矛与盾

逆向工具攻「看懂」这一层：闭源二进制、加壳混淆，AI 一条命令拆开。玄圭守「可信」这一层：安全不靠藏、全靠验——代码随便看，混淆随便破，钥匙不在代码里，验签对规范化字节重算，改一个字节、套一层编码、拆包重包，探针当场识破。

盾每天对着矛的招法排练：探针组防的编码混淆（Base64 套娃、十六进制伪装、嵌套回执），与逆向攻防中「加壳免杀」是同族技巧。矛越锋利，盾的排练越真实。

## 命名由来

「玄圭」出自《尚书·禹贡》：大禹治水功成，**玄圭告厥成功**——以玄圭为信物，向天宣告任务已验证完成。华夏最早的「验收回执」，就是这块黑色的玉。任何智能体接上玄圭，交出的每一份回执都如玄圭在握：验讫为信，不可伪造。

命名属火斗云体系（与火斗讳·天罡同脉的道统谱系），呼应元法则 MR-036 阴阳五行闭环。

## 30 秒接入

在智能体的 MCP 配置里加一段（零第三方依赖，只要 Python 3.10+）：

```json
{
  "mcpServers": {
    "xuangui": {
      "command": "python3",
      "args": ["/path/to/xuangui/server.py"],
      "env": { "AXIOM_KEY": "<你的64位hex密钥>" }
    }
  }
}
```

然后智能体即可调用四个工具：

| 工具 | 作用 |
| --- | --- |
| `xuangui_verify_receipt` | 验证回执：规范化重算 HMAC + 时间新鲜度 + 外部锚点 |
| `xuangui_run_probes` | 红队探针组：篡改 / Base64 混淆 / 双重编码 / 嵌套回执 / 锚点调包 / 过期时间戳 |
| `xuangui_health_report` | 体检报告 + 证据边界声明 |
| `xuangui_make_receipt` | 签发回执（演示 / 测试） |

## 三大能力

1. **验签**：对规范化字节重算 HMAC-SHA256，常数时间比较；键顺序、Unicode 一视同仁。
2. **探针**：服务可以对自己打红队——已知攻击形状全部拒绝，才算健康。
3. **证据边界**：每个判定都标注「直接观察 / 推断」，不伪造确定性，不篡改历史。

## 与 AxiomGate 的关系

AxiomGate（元极恒一闸机）是内嵌在作品里的锁；玄圭把锁抽成标准接口。两者共享同一条进化纪律：**只增不覆盖，版本可生长**。

## 对标

| | REA（逆向一切） | 玄圭 |
| --- | --- | --- |
| 形态 | CLI + MCP 服务器 | MCP 服务器（零依赖） |
| 能力 | 统一逆向工具 | 统一可信验证 |
| 接入 | 一条命令 | 一段 JSON 配置 |
| 争议面 | 逆向授权风险 | 仅验证自身数据，无逆向 |

## 证据边界声明

本作品所有安全判定基于当次输入的规范化重算与直接观察；推荐的置信度表述属于推断，不构成绝对证明。服务不联网、不外发数据、不存储历史状态。
